# DraftKings NFL Classic - Scoring Rules
(Reference for Tinker Tinker weekly DFS contests)

## Offense

| Stat | Points |
|---|---|
| Passing TD | +4 |
| 25 Passing Yards | +1 (i.e. 0.04 pts/yard) |
| 300+ Yard Passing Game | +3 bonus |
| Interception Thrown | -1 |
| Rushing TD | +6 |
| 10 Rushing Yards | +1 (i.e. 0.1 pts/yard) |
| 100+ Yard Rushing Game | +3 bonus |
| Receiving TD | +6 |
| 10 Receiving Yards | +1 (i.e. 0.1 pts/yard) |
| 100+ Receiving Yard Game | +3 bonus |
| Reception | +1 (PPR) |
| Punt/Kickoff/FG Return TD | +6 |
| Fumble Lost | -1 |
| 2 Pt Conversion (Pass, Run, or Catch) | +2 |
| Offensive Fumble Recovery TD | +6 |

## Defense/Special Teams (DST)

| Stat | Points |
|---|---|
| Sack | +1 |
| Interception | +2 |
| Fumble Recovery | +2 |
| Punt/Kickoff/FG Return TD | +6 |
| Interception Return TD | +6 |
| Fumble Recovery TD | +6 |
| Blocked Punt or FG Return TD | +6 |
| Safety | +2 |
| Blocked Kick | +2 |
| 2 Pt Conversion/Extra Point Return | +2 |
| 0 Points Allowed | +10 |
| 1-6 Points Allowed | +7 |
| 7-13 Points Allowed | +4 |
| 14-20 Points Allowed | +1 |
| 21-27 Points Allowed | 0 |
| 28-34 Points Allowed | -1 |
| 35+ Points Allowed | -4 |

### Scoring notes
- Points Allowed (PA) only counts points surrendered while the DST unit is on the field
  (i.e. does NOT include points off the offense's own turnovers).
- The following count as points allowed against the opposing DST: rushing TDs, passing TDs,
  offensive fumble recovery TDs, punt/kick/FG return TDs, blocked FG/punt return TDs, 2pt
  conversions, 2pt/XP returns, extra points, field goals.
- A fumble recovery is awarded to a DST if that team's OFFENSE recovers a fumble committed
  by the opposing defense (e.g., after an offensive turnover) — edge case, rare.

## Lineup Requirements (Classic)
- 9 roster spots, must include players from at least 2 different NFL games:
  - 1 QB
  - 2 RB
  - 3 WR
  - 1 TE
  - 1 FLEX (RB/WR/TE)
  - 1 DST
- Salary cap: $50,000
- Player pool = active rosters for teams in the contest's Game Set; pool can be adjusted
  up to 48 hours before lock if a team makes roster moves after the pool is finalized.

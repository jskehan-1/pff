# Flounder League - Season-Long Scoring Rules
(Reference only - secondary use case, keeper/draft board for next season)

Confirmed against the official league rules export ("flounder rules.xlsx").

## Passing
- Yards: 0.04 pts/yard
- TD: +4
- INT: -2

## Rushing
- Yards: 0.1 pts/yard
- TD: +6

## Receiving
- Yards: 0.1 pts/yard (all positions)
- TD: +6 (all positions)
- Reception (PPR), POSITION-SPECIFIC:
  - QB/RB/WR: 1.0 pt/reception
  - TE: 1.35 pts/reception

> IMPORTANT: this reception scoring is position-specific — do not apply a flat PPR value
> across all positions when computing Flounder point totals from raw stats.

## League format (context)
- 12-team keeper auction league, $200 auction budget
- Roster: 20 total (10 starters + 10 bench)
- Starters: QB1, RB2, WR3, TE1, FLEX1 (RB/WR/TE), OP1 Super Flex (QB/RB/WR/TE), DEF1
- Keeper rule: max kept 3x; cost = prior year value x1.5 (round up, min $5)

keeper tracking, trade log, and draft dashboard details.
